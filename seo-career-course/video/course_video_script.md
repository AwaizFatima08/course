# SEO Career Course: Chapter Video Script (English and Urdu narration)

**Format:** 16:9, 1920 x 1080, 24 fps. One video per chapter, 3 to 5 minutes each.
**Style:** Motion-graphic explainer. Narration over animated diagrams, slides and screen recordings. No talking head.
**Tracks:** One video per language, with its own narration. On-screen text in each language. Urdu uses Noto Nastaliq Urdu. English uses the course palette (blue #1f6feb, navy #0b3d91).

Each chapter has four scenes:
1. **Title card** (5 s): chapter number and title.
2. **Core idea** (60 to 90 s): the main concept, drawn in the animated diagram from the course.
3. **Tools and steps** (60 to 120 s): the tool or workflow, shown with a screen recording or a simple animated mock-up.
4. **Practice and recap** (30 to 45 s): the exercise, and three summary points.

## Chapter 2: How Search Engines Work

**Scene 1: Title card**
- EN: "Chapter 2. How Search Engines Work."
- UR: "باب 2۔ سرچ انجن کیسے کام کرتے ہیں۔"

**Scene 2: Core idea (diagram: crawl, index, rank, Figure 2.1)**
- EN: "Search engines do three things. They crawl pages by following links. They index the content they read. Then they rank the pages when someone searches."
- UR: "سرچ انجن تین کام کرتے ہیں۔ وہ لنکس کو فالو کرتے ہوئے صفحات کرول کرتے ہیں۔ وہ جو مواد پڑھتے ہیں اسے انڈیکس کرتے ہیں۔ پھر جب کوئی سرچ کرتا ہے تو صفحات کو رینک کرتے ہیں۔"

**Scene 3: Snippet anatomy (diagram: Figure 2.2)**
- EN: "The title, the URL, and the meta description are the parts you control in a search result. Keep the title about 50 to 60 characters."
- UR: "ٹائٹل، URL اور میٹا ڈسکرپشن سرچ نتیجے کے وہ حصے ہیں جو آپ کنٹرول کرتے ہیں۔ ٹائٹل تقریباً 50 تا 60 حروف رکھیں۔"

**Scene 4: Practice and recap**
- EN: "Practice: find the title tag of a page using View Page Source. Recap: crawl, index, rank. Follow Google's published rules and never promise guaranteed rankings."
- UR: "مشق: View Page Source سے کسی صفحے کا ٹائٹل ٹیگ تلاش کریں۔ خلاصہ: کرول، انڈیکس، رینک۔ گوگل کے شائع شدہ اصولوں پر عمل کریں اور یقینی رینکنگ کا وعدہ نہ کریں۔"

## Chapter 5: Keyword Research

**Scene 1: Title card**
- EN: "Chapter 5. Keyword Research."
- UR: "باب 5۔ کیورڈ ریسرچ۔"

**Scene 2: Core idea (diagram: search intent, Figure 5.1)**
- EN: "Every search has an intent: learn, go somewhere, compare, or buy. A page ranks only when it matches the intent. Check the current results before you write."
- UR: "ہر سرچ کا ایک ارادہ ہوتا ہے: سیکھنا، کہیں جانا، موازنہ، یا خریدنا۔ کوئی صفحہ تبھی رینک کرتا ہے جب وہ ارادے سے میل کھائے۔ لکھنے سے پہلے موجودہ نتائج دیکھیں۔"

**Scene 3: Keyword process (animated steps)**
- EN: "Brainstorm seed keywords. Expand them with autocomplete and People also ask. Check the results. Group keywords into clusters, then map each cluster to one page."
- UR: "بنیادی کیورڈز سوچیں۔ آٹو کمپلیٹ اور People also ask سے انہیں بڑھائیں۔ نتائج چیک کریں۔ کیورڈز کو کلسٹرز میں گروپ کریں، پھر ہر کلسٹر کو ایک صفحے سے جوڑیں۔"

**Scene 4: Practice and recap**
- EN: "Practice: build a list of 60 keywords for a local business and map them to four pages. Recap: intent first, then clusters."
- UR: "مشق: ایک مقامی کاروبار کے لیے 60 کیورڈز کی فہرست بنائیں اور انہیں چار صفحات سے جوڑیں۔ خلاصہ: پہلے ارادہ، پھر کلسٹرز۔"

## Chapter 6: Technical SEO and Site Audits

**Scene 1: Title card**
- EN: "Chapter 6. Technical SEO and Site Audits."
- UR: "باب 6۔ ٹیکنیکل SEO اور سائٹ آڈٹ۔"

**Scene 2: Core idea (diagram: site architecture, Figure 6.1)**
- EN: "Technical SEO makes sure search engines can reach, read, and store the right pages. Important pages should be three clicks or fewer from the homepage."
- UR: "ٹیکنیکل SEO یقینی بناتا ہے کہ سرچ انجن درست صفحات تک پہنچ سکیں، انہیں پڑھ سکیں اور محفوظ کر سکیں۔ اہم صفحات ہوم پیج سے تین کلک یا اس سے کم پر ہونے چاہئیں۔"

**Scene 3: Audit workflow (screen recording: Screaming Frog and PageSpeed Insights)**
- EN: "Review Search Console. Crawl the site with Screaming Frog. Test speed with PageSpeed Insights. Then write a priority list: critical, high, and low."
- UR: "Search Console کا جائزہ لیں۔ Screaming Frog سے سائٹ کرول کریں۔ PageSpeed Insights سے رفتار جانچیں۔ پھر ترجیحی فہرست بنائیں: نازک، زیادہ، اور کم۔"

**Scene 4: Core Web Vitals and recap**
- EN: "Core Web Vitals measure loading, responsiveness, and visual stability. Recap: a good audit lists the problem, the evidence, the fix, and the owner."
- UR: "Core Web Vitals لوڈنگ، ردعمل اور بصری استحکام کو ناپتے ہیں۔ خلاصہ: اچھے آڈٹ میں مسئلہ، ثبوت، حل اور ذمہ دار شخص شامل ہوتا ہے۔"

## Production notes

- **Voice:** English and Urdu narration must be reviewed by a human before publishing. Urdu narration needs a native speaker to check pronunciation of technical terms. The Urdu text is written to be read as a direct translation, so the voice artist may need to adjust phrasing.
- **Approval:** the owner (Homi) approves every voice-over before use. Health or medical claims need review. This course has none, but check any added claim.
- **Captions:** burn in captions in both languages so each video works with sound off.
- **Music:** use only royalty-free music with a licence that allows commercial use, and record the licence in a credits file.
